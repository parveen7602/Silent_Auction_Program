##  How It Works  
1. The program asks each participant for their **name** and **bid amount**.  
2. After entering a bid, the user specifies whether there are **more bidders**.  
3. If yes, the screen is cleared, and the next bidder enters their bid.  
4. When no more bidders remain, the program finds the **highest bid** and announces the **winner**.
